# SoldArte FerreMALL

SoldArte FerreMALL es un marketplace y plataforma web para la comercialización de herramientas, insumos y materiales de construcción. Permite a los clientes explorar y comparar catálogos de distintas ferreterías en un solo lugar, brindándoles la libertad de elegir en qué establecimiento realizar sus compras.

## Tecnologías Utilizadas

- **Framework:** TanStack Start (React + Vite)
- **Despliegue:** Vercel
- **Estilos:** Tailwind CSS / shadcn/ui
- **Asistente Virtual:** Google Gemini (`gemini-2.5-flash`) mediante Server Functions de TanStack Start
